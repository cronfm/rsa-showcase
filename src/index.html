FREDERIK CRONJÉ’S ORIGINAL IMPLEMENTATION

The probabilistic
C# code.

PrimeTest.IsNotPrime draws random bases, calls the recursive UInt128 square-and-multiply method, and returns as soon as a witness detects a composite.

The four original files are preserved from the RSA repository and compiled together. The database sampler and parallel verification harness are included. Source checks verify that their contents remain unchanged.

The browser demonstration uses a JavaScript mirror. Additional RSA and comparison code is listed separately in the source picker.
